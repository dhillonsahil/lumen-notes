## Post-Phase Enhancements & UX Refinements (Verified)
1. **Borderless Writing Canvas**: Removed focus rectangles and outline borders from `.editor-title-input`, `.tiptap`, `.ProseMirror`, and content areas using targeted CSS overrides while preserving keyboard accessibility rings on interactive buttons.
2. **100% Canvas Height & Click-to-Focus**: Expanded `.editor-scroll-area`, `.editor-content-wrapper`, and `.tiptap` to stretch to 100% canvas height. Clicking any empty space on the scroll canvas automatically focuses the editor at the end of the text.
3. **Global Sidebar Counts Independent of Active View**: Decoupled sidebar counts from the filtered note list view. Replaced filtered count estimation with global multi-query aggregation (`reloadCounts`), ensuring All Notes, Favorites, Archive, Trash, and custom folder badges always show accurate database totals regardless of the active view.
4. **Version Snapshot Restore Conflict Resolution**: Fixed the snapshot restore revision conflict error (`Conflict: expected revision 14, but current is 15`) by setting content with `{ emitUpdate: false }`, cancelling pending debounced autosaves, and immediately committing the restored revision to state and local refs.
5. **Compact Attachment Drawer & Native OS App Launching**:
   - Relocated the `.editor-attachments` section to sit directly below the note title input and above the editor canvas with natural minimum height, preventing attachments from being pushed below empty space.
   - Added `open_attachment` Tauri backend command executing `cmd /C start` (Windows) or `xdg-open` (Linux). Clicking any non-image attachment chip directly opens the file in its default OS viewer (Acrobat, Word, Excel, VLC, etc.). Images open seamlessly in the interactive Lightbox.
6. **Export Destination Folder Picker**: Replaced blind browser downloads with the native File System Access API (`window.showSaveFilePicker`). Users can now browse and select the exact folder location and filename when exporting individual notes (Markdown, HTML, Plain Text, JSON) or full workspace backup archives.
7. **Custom macOS Notes-Style Context Menu**: Intercepted right-click events in the writing canvas and selection areas to present a tailored context menu with quick tools: Bold, Italic, Strikethrough, Code, Headings (H1/H2/H3), Bulleted & Numbered Lists, Task Lists, Blockquotes, Link insertion, Inline Image insertion, File Attachment, and Clipboard operations (Cut, Copy, Paste).
8. **Apple-Inspired Rounded Confirmation Modals**: Replaced all native browser popups (`window.confirm`, `localhost:1420 says`) with a custom macOS-style `ConfirmModal` featuring backdrop blur (`blur(12px)`), smooth scale animations, rounded corners (18px), soft red/amber status iconography, and keyboard navigation (`Escape` to cancel, `Enter` to confirm). Used for note deletion, attachment deletion, snapshot restoration, and folder deletion.
9. **Responsive Editor Toolbar & 3-Dot Overflow Menu**: Added a 3-dot (`...`) More Options menu to the editor toolbar. On narrow windows or compact views, secondary actions (Version History, Export options, Code blocks, Quotes, Horizontal rules, Strikethrough) collapse cleanly into the 3-dot menu so tools are never cut off.
10. **Collapsible / Compact Sidebar on All Screen Widths**: Fixed the desktop sidebar toggle check and added intuitive sidebar toggle buttons to both the NoteList header and Sidebar header, allowing users to collapse and expand the folder pane at any time on desktop and mobile (`Ctrl+Shift+S`).
11. **Ascending / Descending Sorting & Dark Mode Dropdown Contrast**: Added an Ascending/Descending toggle button (`ArrowUpNarrowWide` / `ArrowDownWideNarrow`) next to the sort selector. Styled all dropdown selects and `<option>` popups with explicit dark mode and light mode backgrounds and tokens.
12. **Persistent "New Note" Button**: Kept the New Note (`+`) button always visible in the note list and sidebar. When clicked from Trash, it automatically switches to All Notes and instantiates a new note without user friction.
13. **`Ctrl + S` Manual Snapshot Creation Without Overwriting**: Hooked `Ctrl + S` to immediately flush pending editor changes to disk and create a brand-new version snapshot in SQLite history, displaying a floating status pill (`Snapshot saved (Revision X)`).
14. **Custom Lumen Brand Icon**: Designed a unique, luminous multifaceted golden prism and folded quill emblem representing "Lumen" (illumination of thoughts). Generated high-resolution desktop platform icons (`icon.ico`, `icon.icns`, `icon.png`, `Square*.png`, `StoreLogo.png`), web favicon, and in-app brand header.
15. **Tauri Window & Taskbar Icon Runtime Binding**: Bound window initialization directly to `app.default_window_icon()` in `src-tauri/src/lib.rs` and cleaned cached build artifacts so running `tauri dev` or production binaries immediately renders the custom Lumen Notes brand icon in the OS titlebar and taskbar.
16. **Strict Archive View Filtering (`only_archived`)**: Added `only_archived` flag to `NoteFilter` across Rust SQLite storage and TypeScript IPC. Navigating to the Archive view now strictly isolates and displays only archived notes, completely preventing unarchived notes from appearing.
17. **Sequential Version Counter in Snapshot History**: Replaced raw database revision numbers (`Revision 18`, `Revision 25`) in `SnapshotModal` with clear, user-friendly sequential version counters (`Version 1`, `Version 2`, `Version 3`, ..., `Version N`) ordered chronologically.
18. **Complete Trash / Bin Management (Empty Bin & Editor Trash Banner)**: Added an "Empty" button in the NoteList header for quick bin purging, and added an interactive Trashed Note banner at the top of the editor canvas with "Restore Note" and "Delete Permanently" actions.
19. **Auto-Focus Title on New Note & Enter to Jump to Editor Body**: Creating a new note automatically focuses the title input. Pressing `Enter` in the title field immediately jumps keyboard focus to the start of the rich-text note body for seamless mouse-free writing.
20. **Automated Verification**: All 27 real-browser Playwright E2E tests, 13 Vitest unit tests, and 7 Rust backend integration tests passed with 0 errors. Production build verified with `npm run build` in 816ms.
21. **Note Pinning Surfaces Note to Top & Pinned/Notes Visual Sections**: Clicking Pin on any note immediately surfaces the note to the very top of the list in state and reloads the authoritative database order (`ORDER BY pinned DESC`). Added Apple Notes-style `PINNED` and `NOTES` section labels that dynamically appear when notes are pinned.
22. **Snapshot Deduplication & Trailing Whitespace Normalization**: Manual saves (`Ctrl+S`) and snapshot creations compare the draft with the latest snapshot using trailing whitespace normalization (`trim_end()` on title and document text nodes). Identical saves or edits with only trailing spaces/newlines do not increment version counters or insert duplicate database records; the user is notified with `"No changes to save — snapshot already up to date"`. Real character edits or formatting changes generate new sequential snapshots.
23. **Multi-Platform GitHub Actions CI/CD Release Workflow (`release.yml`)**: Created `.github/workflows/release.yml` with `tauri-apps/tauri-action@v0` targeting `ubuntu-22.04` (generating `.deb`, `.rpm`, `.AppImage`), `windows-latest` (generating `.msi`, `.exe`), and `macos-latest` (generating `.dmg`, `.app`), building and packaging all production release artifacts automatically on release tags.
24. **Settings & Snapshot Modal Autosave vs. Snapshot Policy Clarification**: Added clear, prominent explanations in `SettingsModal` and `SnapshotModal` clarifying that drafts autosave continuously every 700ms in the background to local SQLite, while Version History snapshots are deliberate restore points captured on manual save (`Ctrl + S`) or via the `+ Snapshot` button.
25. **Dynamic Measured Responsive Toolbar & 3-Dot Overflow Menu**: Added a `ResizeObserver` to `EditorToolbar` so it dynamically adapts to actual editor container width:
    - **Wide / Full Screen (`>= 940px`)**: All tools fit natively on the toolbar; the 3-dot More button is cleanly hidden (`showMoreButton = false`), resolving toolbar clutter when all options are present.
    - **Compact Window (`700px - 940px`)**: Secondary formatting and export collapse into the 3-dot menu.
    - **Narrow / Small Window (`< 700px`)**: Lists, Find, and secondary media collapse into the 3-dot menu so no toolbar items overflow or get clipped offscreen.
26. **Sponsor Links & Heart Sponsor Button**: Added a dedicated "Support & Sponsor" section to `SettingsModal` linking directly to Buy Me a Coffee (`https://buymeacoffee.com/isahildhillon`) and the GitHub repository (`https://github.com/dhillonsahil/lumen-notes`), and added an interactive Sponsor button with a heart icon in the sidebar footer right next to Settings.
